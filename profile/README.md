## 💡 About LinkRo

지하철을 이용하다 보면 단순히 경로를 찾는 것만으로 끝나지 않습니다.

- 어느 방향으로 가야 하는지
- 이용하려는 시간대가 얼마나 혼잡한지
- 여러 명이 어디에서 만나는 것이 좋은지
- 약속 상대의 이동 상황을 어떻게 확인할지

LinkRo는 이러한 지하철 이용 과정의 여러 불편을  
**AI와 실제 지하철 데이터를 활용하여 하나의 흐름으로 연결하는 것**을 목표로 합니다.

---

## ✨ Main Features

### 🗺️ 경로 탐색
출발역과 도착역을 기준으로  
이동 시간과 경로 정보를 제공합니다.

### 🤖 AI 중간역 추천
여러 사용자의 출발역과 이동 조건을 바탕으로  
적절한 중간역을 추천합니다.

사용자가 입력한 자연어 조건은 AI가 분석하고,  
실제 이동 시간과 비용은 경로 탐색 알고리즘을 기반으로 계산합니다.

### 📊 향후 시간대별 혼잡도 확인
서울교통공사의 과거 혼잡도 데이터를 활용하여  
사용자가 이용하려는 시간대의 예상 혼잡 정보를 제공합니다.

### 📸 AI 노선 방향 안내
사용자가 촬영한 지하철 표지판에서

- 노선
- 역 이름
- 방면
- 화살표

등의 정보를 분석하여 사용자가 선택한 경로와 비교하고  
이동해야 할 방향을 안내합니다.

### 👥 약속방
중간역 추천 이후에도 참여자들이

- 추천 결과
- 이동 상태
- 동의 기반 위치 정보

를 함께 확인할 수 있도록 지원합니다.

## 🔀 Git Flow

```text
main
 └── dev
      ├── feat/*
      ├── fix/*
      └── chore/*
```

### Development Process

```text
Issue
  ↓
Branch
  ↓
Development
  ↓
Pull Request
  ↓
Code Review
  ↓
Merge to dev
```

- `main` : 최종 안정 버전
- `dev` : 개발 통합 브랜치
- `feat/*` : 기능 개발 브랜치
- `fix/*` : 버그 수정 브랜치
- `chore/*` : 환경 설정 및 기타 작업
